# libopencv-flann-tests - Clustering and search in multi-dimensional spaces (tests)

This is a `build2` package containing the test suite for the
[`OpenCV`](https://github.com/opencv/opencv) library's `flann` module.
Both upstream test files are covered, unmodified.


## Importable targets

This package exports no targets.


## Configuration variables

This package provides no configuration variables.
