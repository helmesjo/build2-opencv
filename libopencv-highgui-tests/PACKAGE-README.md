# libopencv-highgui-tests - High-level GUI (tests)

This is a `build2` package containing the test suite for the
[`OpenCV`](https://github.com/opencv/opencv) library's `highgui` module.
The single upstream test file is covered, unmodified.


## Importable targets

This package exports no targets.


## Configuration variables

This package provides no configuration variables.
